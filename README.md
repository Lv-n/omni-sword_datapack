# Description
- Omni Sword is a weapon that is made to be overpowered, fully vanilla without mods. I scraped off almost everything Minecraft has to offer and made this project. I'm very proud of this datapack ever since I started it.
- Type in this command to get the item: /function omni:give

  ## Multiple weapons in one
  This item have the ability of the mace, spear and trident at once
  - The Omni Sword have the same ability of the mace
  - Holding right-click and charge any mobs or players to kill them like the spear
  - Able to throw the sword like a trident

  ## Features
  - Hitting a mob/player will summon lightning to nearby mobs or players
  - Sneaking with the Omni Sword will trigger a defense mechanism: It will restore durability of armors you're wearing. It will summon a forcefield, shielding the user from basic void traps, mace user, or even orbital strike cannons and railguns. It can even regenerate your health and saturation instantly and give you maxed out resistance effect
  - Can one-hit any mobs or players, including creative players using the damage_type component in vanilla Minecraft
  - immune to any type of damage like: throwing in lava, struck by lightning, explosion or even being thrown in cactus itself
